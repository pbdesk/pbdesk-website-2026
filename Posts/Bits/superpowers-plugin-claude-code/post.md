# Superpowers Plugin for Claude Code

**Post Type:** Bit

## Main Body

Claude Code is useful when you know what to ask. It gets more reliable when it also knows how to work.

Superpowers is a plugin that adds a structured software development method to Claude Code. Instead of jumping straight into edits, it nudges the agent through better habits: clarify the idea, shape a plan, write tests first when the task calls for it, review the work, and debug from a root cause instead of guessing.

That sounds formal, but the value is simple. It reduces the number of times an AI coding session turns into a pile of confident changes. For bigger tasks, Superpowers can help Claude ask sharper questions before writing code. For bug work, it pushes investigation before fixes. For test-driven work, it reinforces the red, green, refactor loop so tests prove the change instead of decorating it.

You can install it from the official Claude plugin marketplace:

```text
/plugin install superpowers@claude-plugins-official
```

The plugin is most useful when the task has ambiguity: a feature that needs design, a bug that needs patience, or a refactor that could wander. You can still keep the session conversational, but Superpowers adds guardrails that make the agent behave more like a teammate with a process.

Use it when you want Claude Code to slow down just enough to avoid expensive mistakes.
